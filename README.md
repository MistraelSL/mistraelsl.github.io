# mistraelsl.github.io

Статический каталог персонажей для GitHub Pages. Интерфейс не требует сборщика или внешних JavaScript-зависимостей.

## Структура

- `index.html` — семантическая разметка экранов.
- `assets/css/styles.css` — оформление и адаптивные состояния.
- `assets/js/data.js` — данные фандомов и персонажей.
- `assets/js/dial.js` — круговой SVG-механизм и управление.
- `assets/js/particles.js` — ограниченный фон снега на одном canvas.
- `assets/js/app.js` — переходы между экранами и карточка персонажа.

Отсутствующие изображения автоматически заменяются ледяными градиентами. Ссылки скачивания включаются только при наличии пути к файлу в `data.js`.
